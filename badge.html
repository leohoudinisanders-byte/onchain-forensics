What it promises

  • Cached grades only. No chain reads, so the badge is fast and cannot be used to burn node budget. It reflects the last measurement, roughly every six hours.
  • Never a broken image. An ungraded or unknown contract returns a neutral NOT GRADED badge with HTTP 200 instead of a 404, and a lookup failure falls back the same way.
  • No key, no payment, no attribution required. CORS is open. Linking back to the token page is appreciated, not enforced.
  • No hidden claims. The badge reports what was measured (transfers and wallets over the last 500 blocks) and nothing about price.
