Safeguards against compromised responses. Consuming agents should be able to trust this service even under a worst-case server compromise:

  • No instructions in responses. Every response is a deterministic, schema-fixed composition of on-chain reads (eth_call / eth_getLogs / XRPL JSON-RPC). No LLM or free-text model generates response content, so responses cannot carry injected prompts, malicious instructions or persuasive text. The only human-readable strings are template-composed from numeric on-chain values.
  • Manipulated data is independently checkable. Every field is derived from public mainnet state; a suspicious consumer can re-verify any response against their own RPC at the same block. Settle-safe responses embed an rpc_verification evidence trail (per-node read outcomes), and 402s bind payment to a resource URL, so data and payment can be replayed and audited on-chain.
  • Reads are not built on shared gateways. Base and Ethereum reads are served from a dedicated provider endpoint (Alchemy) whose key this service controls, with the public gateway rotation kept only as a fallback. Public gateways under load answer eth_call with short or empty results; those are detected as malformed and re-read instead of being reported as a zero balance. Every payload states whether its scan window was complete, partial or unavailable.
  • Payments cannot be silently redirected. The payTo address is a fixed constant in the deployed service, echoed in every PAYMENT-REQUIRED challenge and in the free directory (?endpoint=info). Payments are EIP-3009 signed authorizations verified and settled by independent facilitators (Coinbase CDP primary, with fallbacks), not by this service, so a server-side attacker cannot move funds or alter the payment terms a paying agent already signed.
  • Change control on agent-facing content. The API definition, pricing and payment requirements are code-deployed from a private repository; deployments are reviewed by the operator, and the OpenAPI contract is served from a separate GitHub Pages origin that the runtime cannot rewrite, so advertised and actual behavior cannot drift silently. Free discovery (X-402-Discovery: 1) lets any marketplace re-audit the exact payment terms an agent would sign, at zero cost.
