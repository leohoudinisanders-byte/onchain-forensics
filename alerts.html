How to subscribe

Payment is USDC on Base over x402, the same rail the rest of this API settles on. The email is required before payment, so you cannot pay for alerts we cannot deliver.

curl -X POST "https://api.onchainforensics.dev/functions/alertsSubscribe" \
  -H "Content-Type: application/json" \
  -d '{"email":"you@example.com","plan":"month","watchlist":["0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913"]}'

That returns a 402 challenge for $29.00. Pay it with any x402 client and you get back an alerts_key and an expires_at. Check status any time:

curl -X POST "https://api.onchainforensics.dev/functions/alertsSubscribe" \
  -H "Content-Type: application/json" -H "X-Alerts-Key: fxa_..." \
  -d '{"action":"status"}'
No custodial account, no card on file. USDC in, thirty days of alerts out. Renew by paying again with the same email; the subscription extends rather than stacking.
