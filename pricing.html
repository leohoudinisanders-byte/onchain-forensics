Pricing

Every route is priced per call in USDC on Base, settled through x402. No subscription is required for the API, no account, no API key. You pay for the call, you get the answer, the receipt is on-chain.

Try it free first

One free call per route, every day

Add trial=1 to any route and it answers without payment, once per day per caller. The payload is the same shape the paid call returns, so you can build the integration before you spend anything.

How payment works

  • You call a route. If payment is required, the response is an HTTP 402 with an x402 challenge: the exact amount in atomic USDC, the asset, the payTo address, and the network (eip155:8453, Base).
  • You sign an EIP-3009 transfer authorization. The facilitator relays it, so you need no ETH for gas.
  • The call is retried with the payment header and answered once settlement confirms.
  • No cards, no stored payment credentials, no subscription on the API path.
