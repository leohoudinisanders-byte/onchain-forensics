Versioning and deprecation

Every response and the OpenAPI document carry a semantic version. What that means in practice:

  • Patch and minor versions only add fields. Existing field names, types and enum members never change meaning inside a major version.
  • Breaking changes ship under a new route name (for example forensicsVerdict2) with the old route kept live for at least 90 days after the announcement.
  • Deprecation notice is published here and in the OpenAPI document at least 90 days before a route stops answering, and the old route returns a Deprecation header once the notice is live.
  • Removal requires the notice period to have elapsed and is never silent. A route that 404s without notice is our bug, not your problem to absorb.
  • Cache rebuilds are not API changes. Grades can change because the chain changed. A grade change is data, not a version bump.

Install inside an agent

The same routes ship as an MCP server so a framework can load them without code:

npx -y onchain-forensics-mcp

Six tools, stdio transport, zero dependencies. On a spent free allowance the tool returns the decoded x402 challenge instead of an error, so the calling agent knows the exact price.
